# Homebrew tap

Homebrew formulae for [Beanstalk](https://github.com/kpb/beanstalk) and
[d6roll](https://github.com/kpb/d6roll).

Install either tool directly (Homebrew taps this repository automatically):

```sh
brew install kpb/tap/beanstalk
brew install kpb/tap/d6roll
```

The d6roll formula supports macOS (Intel and Apple Silicon) and Linux (amd64).
